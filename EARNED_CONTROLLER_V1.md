# Earned Controller V1

## Purpose

This record freezes the smallest controller supported by the project before
owner-controlled ecological testing. It is a custody and decision record, not
a new model-facing feature.

> Preserve complete chronology as exact external custody. Reconstruct a
> bounded decision frame containing exact purpose, current world state,
> readable orientation, signal-bearing event identity, and remaining
> resources. Let Qwen explicitly choose which exact payload to reacquire.

## Resident decision frame

The model receives the exact task and active step, current candidate and
budgets, hierarchical readable P0, candidate-bound observation identities, one
ordered signal-bearing event frame, stable exact payload addresses, a compact
capability contract, and a server-capped 512-token private reasoning allowance
that is separately custodied and omitted from later chronology.

The host does not add summaries, rankings, inferred relevance, relationship
graphs, or semantic sufficiency judgments.

## Canonical payload correction

Experiment 018 showed that an explicit reopen could manufacture a new
`RES-*` address for the same underlying exact body. V1 corrects identity and
provenance only:

```text
PAYLOAD OBS-0002
  accessed by EVT-0004
  accessed again by EVT-0009
```

Each access remains a new ordered event. Qwen must still request every reopen.
No payload is automatically injected, cached into view, ranked, or suppressed.
The event retains readable signal; the canonical address alone is not treated
as information.

## Evidence boundary

The controller combines results from Experiments 003–018. Experiment 018 is
the fresh large-world crossover: R50 physically exhausted all four paths,
whereas X25 continued all four and completed both observation paths. That is
an existence proof, not a reliability result.

Semantic memory, relationship graphs, embeddings, host-selected relevance,
duplicate-read suppression, and more reasoning remain excluded.

## Next falsifying test

Experiment 019 uses two repairs from the owner-controlled Addressable
Information Layer source snapshot: an exact source/reopen contract repair and
a current candidate-bound verifier-observation repair. It asks whether the
assembled controller performs useful work outside a generated toy repository
while retaining correction and closure headroom.
