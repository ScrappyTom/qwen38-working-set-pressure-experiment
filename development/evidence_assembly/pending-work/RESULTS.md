## Decision

Retain the host core and close both consultation responses. The initial grouping
and semantic judgments are researcher assistance; the original model runs remain
closed. No coached continuation, additional seed, reasoning change, budget extension
or new host feature occurs in this tranche.

The substantive lesson is to recover the proposed work and its exact support as a
usable unit. The stored proposal was already sound; writing it again from a smaller,
less informative state made it worse. The present host can support recovery and
durable checked work when the right selection is supplied. Its storage is not the
missing component, and a correct explanatory answer is not the missing task outcome.

The next narrow host candidate is to let work_on select saved ACTION handles as
well as RESULT handles. Its current contract forces a separate acquisition for a
rejected proposal; our invalid first script made that boundary concrete. Removing
that compulsory step could leave room for submission in this particular route.
This would extend the operation contract, not merely rename a field. Qualify exact
payload identity, source eligibility, stale guards and complete native admission
before exposure; do not add action replay, silent guard refresh or automatic edits.
The consultation does not prove that Qwen would use that extension correctly or
that it would reduce total work. After qualification, assess one completed uncoached
contribution rather than starting another vocabulary study. No further live task
run is included in this now-consumed consultation package.
