   Missing references are reported when the value is retrieved with interpolation,
   rather than when the configuration text is read. For example::

      >>> import configparser
      >>> basic = configparser.ConfigParser()
      >>> basic.read_string('[main]\nvalue=%(missing)s\n')
      >>> try:
      ...     basic.get('main', 'value')
      ... except configparser.InterpolationMissingOptionError as error:
      ...     print(error.reference)
      missing
      >>> basic.get('main', 'value', raw=True)
      '%(missing)s'
      >>> basic.set('main', 'missing', 'supplied')
      >>> basic.get('main', 'value')
      'supplied'

   ``raw=True`` returns the stored value without resolving its reference. It does
   not create the missing setting. Extended interpolation can refer to another
   section; that section and setting must be present for resolution::

      >>> extended = configparser.ConfigParser(interpolation=configparser.ExtendedInterpolation())
      >>> extended.read_string('[main]\nvalue=${other:missing}\n[other]\n')
      >>> try:
      ...     extended.get('main', 'value')
      ... except configparser.InterpolationMissingOptionError as error:
      ...     print(error.reference)
      other:missing
      >>> extended.get('main', 'value', raw=True)
      '${other:missing}'
      >>> extended.set('other', 'missing', 'supplied')
      >>> extended.get('main', 'value')
      'supplied'
