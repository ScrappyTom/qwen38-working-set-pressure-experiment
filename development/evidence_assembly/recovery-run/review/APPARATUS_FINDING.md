# Validity and limits

This is one bounded uncoached development attempt using a researcher-selected
checkpoint from a previous task. The copied source selection came from Qwen, but
its ancestry includes researcher assembly assistance. No reviewer intervened between
the eight current decisions. Those facts support uncoached continuation from reused
work, not autonomous creation of the initial information state or an end-to-end
backport. A new seed does not make the task fresh capability evidence.

The previous run's C05 view is reconstructed before resetting the new attempt's
allowance and labeling 75 archived actions prior work. Only the declared current
task/interface/state and real operation results enter the model. Future proposal
assessments, consultation facts, researcher-scripted successful routes and missing
implementation are not injected. Exact replay validates the frozen sources and
all actual transitions; no transport or host exception invalidates the observed
operations. Closure is model-request-budget exhaustion, not an interrupted response.

The model never acquires library implementation or the recoverable historical
proposal. It saves different work, which is allowed, but does not establish the
behavior those expectations describe. No selected evidence leaves the input, no
historical recovery occurs, and the input ceiling is not approached. There is no
context-pressure outcome, group-replacement qualification or failed-check recovery.
Private reasoning is omitted immediately as declared; that is distinct from later
source loss. Seven feedback deliveries occur; the terminal edit has no next request.

The host enforces exact edit eligibility and checked submission. No submission is
attempted, so this is not a successful exercise of the submission guard. Every edit
being accepted says nothing by itself about the intended diagnostic values or
documentation accuracy. Independent review finds concrete errors without revising
the original run or adding actor operations. A failed reviewer check is not an
actor correction cycle.

The exact checker covers saved work, actual lookup/transport paths and restoration
faults; it is not an exhaustive semantic validator of every task assertion. Direct
review identifies missing exact class/argument/message checks. Documentation has
always required direct assessment; its failing examples and false attribute prose
are reported separately. An already failing baseline limits aggregate mutation
claims; the passing Basic method's new mutation failures supply narrower evidence.

Settings stay fixed at medium/uncapped for all requests. Ordinary responses finish
inside the prospective reserve here, but one successful termination profile cannot
bound future outputs. The changed checkpoint, seed, allowance and shared explanation
preclude assigning cost differences to wording or reasoning allocation. Reviewer
time/inference was not separately metered; loop time is not all development cost.
