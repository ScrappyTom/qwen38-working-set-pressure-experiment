Interpolation Missing Option Error
----------------------------------

When a value references an option that does not exist, a non-raw
:py:meth:`~configparser.ConfigParser.get` call raises
:py:exc:`~configparser.InterpolationMissingOptionError`.  The exception
carries the *option*, *section*, and *reference* of the failing lookup.

BasicInterpolation
^^^^^^^^^^^^^^^^^^

In :py:class:`~configparser.BasicInterpolation`, references use
``%(name)s`` syntax.  The example below triggers the error because
``server`` is not defined:

.. code-block:: python

    import configparser

    cp = configparser.ConfigParser(interpolation=configparser.BasicInterpolation())
    cp.add_section('db')
    cp.set('db', 'host', '%(server)s.local')

    try:
        cp.get('db', 'host')
    except configparser.InterpolationMissingOptionError as e:
        print(e.option)     # 'host'
        print(e.section)    # 'db'
        print(e.reference)  # 'server'

Using ``raw=True`` returns the unresolved template:

.. code-block:: python

    print(cp.get('db', 'host', raw=True))   # '%(server)s.local'

Supplying the missing option resolves the reference:

.. code-block:: python

    cp.set('db', 'server', 'db1')
    print(cp.get('db', 'host'))             # 'db1.local'

ExtendedInterpolation
^^^^^^^^^^^^^^^^^^^^^

In :py:class:`~configparser.ExtendedInterpolation`, references use
``${name}`` syntax.  A cross-section reference is written
``${section:name}``.  The example below fails because ``base`` does
not contain a ``root`` option:

.. code-block:: python

    cp2 = configparser.ConfigParser(interpolation=configparser.ExtendedInterpolation())
    cp2.add_section('base')
    cp2.add_section('app')

    try:
        cp2.get('app', 'path')
    except configparser.InterpolationMissingOptionError as e:
        print(e.option)     # 'path'
        print(e.section)    # 'app'
        print(e.reference)  # 'root'

``raw=True`` again returns the unresolved value:

.. code-block:: python

    print(cp2.get('app', 'path', raw=True))  # '${base:root}/var'

Adding the missing cross-section option fixes the lookup:

.. code-block:: python

    cp2.set('base', 'root', '/opt')
    print(cp2.get('app', 'path'))            # '/opt/var'
