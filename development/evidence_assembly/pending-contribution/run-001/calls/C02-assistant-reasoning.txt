```rst
.. exception:: InterpolationMissingOptionError

   Exception raised when an option referenced from a value does not exist.
   Subclass of :exc:`InterpolationError`.

   This error occurs when :meth:`ConfigParser.get` attempts to resolve an
   interpolation reference but the referenced option (or section) is not
   present in the parser.  The exception carries the *option* being looked
   up, the *section* it belongs to, the *rawval* (the unresolved string),
   and the *reference* that could not be resolved.

   .. code-block:: python

       import configparser

       # --- BasicInterpolation ---
       parser = configparser.ConfigParser(
           interpolation=configparser.BasicInterpolation())
       parser.read_string("\n"
           "[Paths]\n"
           "home_dir: /Users\n"
           "my_dir: %(home_dir1)s/lumberjack\n")

       try:
           parser.get('Paths', 'my_dir')
       except configparser.InterpolationMissingOptionError as e:
           print(e.option)       # 'my_dir'
           print(e.section)       # 'Paths'
           print(e.reference)     # 'home_dir1'
           print(e.args)          # ('my_dir', 'Paths', '%(home_dir1)s/lumberjack', 'home_dir1')

       # raw=True skips interpolation and returns the stored string as-is.
       print(parser.get('Paths', 'my_dir', raw=True))
       # '%(home_dir1)s/lumberjack'

       # Supply the missing option, then the lookup succeeds.
       parser.set('Paths', 'home_dir1', '/Users')
       print(parser.get('Paths', 'my_dir'))
       # '/Users/lumberjack'

       # --- ExtendedInterpolation ---
       parser2 = configparser.ConfigParser(
           interpolation=configparser.ExtendedInterpolation())
       parser2.read_string("\n"
           "[Paths]\n"
           "home_dir: /Users\n"
           "my_dir: ${Other:home_dir}/lumberjack\n")

       try:
```

```
   Exception raised when an option referenced from a value does not exist.
   Subclass of :exc:`InterpolationError`.

   This error is raised by :meth:`ConfigParser.get` when an interpolation
   reference in the option value cannot be resolved because the referenced
   option (or section) does not exist in the parser.  The exception exposes
   the *option* being retrieved, the *section* it belongs to, the *rawval*
   (the unresolved stored string), and the *reference* that failed.

   With :class:`BasicInterpolation` (the default), references use the
   ``%(name)s`` form and are resolved against the current section and
   the ``[DEFAULT]`` section only:

   .. code-block:: python

       import configparser

       parser = configparser.ConfigParser(
           interpolation=configparser.BasicInterpolation())
       parser.read_string("\n"

                               #  '%(home_dir1)s/lumberjack', 'home_dir1')

       print(parser.get('Paths', 'my_dir', raw=True))
```
