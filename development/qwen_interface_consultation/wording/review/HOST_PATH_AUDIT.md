final action, exact tool result and subsequent host decision. No invalidating

separate text fields extracted, post-response runtime check, action selected,

invented, weakened or bypassed. The visible reference was not merely in the
server's response grammar; it was present in the actual system input.

After each action, the host saved the resulting state and ended that path without
another model request. Displayed fixture allowances of 23/22 remaining calls did
not provide a live continuation or correction opportunity in this one-action
comparison. The candidate removes the resource illustration, not this declared

opportunity is unexercised, not a successful correction cycle. All terminal paths

## Byte-count scope remains confusing

W01 described a conflict between the 26-byte source and the 42-byte result-body
record. W03, in the wording condition, manually counted the source and suggested
JSON escaping as a possible explanation. Inspection of
[the payload constructor](../../../../src/working_set_exp/event_frame_v3.py)
confirms that size_bytes/sha256 concern `canonical_json_bytes(values)`: here the
whole `{content: ...}` field object. The source's 26 bytes and its independently
verified file hash remain correct. Recounting the exact supplied object reproduces
42 bytes and hash 484a6b28…; no bytes were missing or corrupted.

The complete tool reference distinguishes full saved results from extracted
field objects, but does not explicitly connect every displayed size to its
serialization boundary. The current wording package targets resource/navigation
authority, so it does not resolve this separate presentation burden. Both models
still selected correct guarded patches. No extra retrieval or incorrect mutation
followed. W03's longer response includes this counting, but neither the transcript
nor four pairs identifies what share of its extra generation the scope caused.

Preserve the already deferred option for accurate host-generated grouping and
explicit object scopes. This repeated friction strengthens the reason to watch
that distinction during multi-turn work; it does not automatically earn another
interface micro-test or adoption of Qwen's earlier inaccurate example views.
