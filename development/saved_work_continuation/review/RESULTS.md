# Saved work survived; completion remained expensive

The assisted continuation reached checked submission in nine model actions.
Qwen corrected its own malformed report, retained the correct first-entry facts,
added the second entry, consumed the actual edit/check feedback and submitted the
same checked candidate. The final 363-byte report independently matches the
captured AST comparisons; all 26 public cases pass. The optimizer was the separate
starting saved repair and was not changed by this trial.

The cost is substantial: **113,857 generated tokens, 183,817 input tokens and
123.63 task-loop minutes**. Model requests account for 123.40 minutes. Completion
does not establish efficient investigation or correct interpretation throughout.
In the final response, Qwen repeatedly misquotes evidence still visible, questions
the correct report and then preserves it because of the actual passing check and
remaining allowance. That persistent error is more informative than the final
accepted-action count alone.

## What the trajectory establishes

- A saved contribution can be corrected and extended across the declared restart.
  C01's first entry has correct facts but invalid JSON. Its actual failed check,
  malformed saved file and reacquired evidence support C05's correction. No
  reviewer silently replaces the failed work.
- The completed C05 artifact survives later input-pressure transitions unchanged
  through checking and submission. Exact edit payloads carry the whole current
  report after its earlier read leaves the prompt.
- All nine model actions are accepted, and every dispatched input receives its
  newest tool feedback. Acceptance includes the first model check's real failure.
  Existing version guards and exact historical recovery remain useful.
- The live path also exhibits removed evidence, immediately omitted rationale and
  misused resident evidence. These have different observed consequences and must
  remain separate in the diagnosis.

This is one reused-task assisted development run, not an unassisted assembly
test, a fresh investigation, a matched efficiency comparison or achievement of
the owner's full long-work goal. The deliberate phase restart is assisted;
subsequent capacity-driven removals are actual pressure events within that path.

## What still needs attention

then spends 13,552 output tokens reconsidering the task. It repeatedly renders
BUILD-A's Weibull return without the unary minus actually present in its input.
The independent assessment confirms the correct captured subtree and report.
The model finally relies on the check and budget without resolving that reading.
This is successful operation with a consequential interpretation problem, not
evidence that all its deliberation was useful or that more context alone fixes it.

C08 also debates a real supplied instruction: reopen historical observations
before relying on them. Its uncertainty concerns whether that applies to checking
an already saved contribution. That distinction merits a neutral, separate Qwen
conversation. Begin with actual records and what they establish; preserve the
unassisted answer before clarification. A new presentation remains conditional

Retain exact storage, independent result access, guarded edits, actual checks and
the tested visible tool requirements. Keep the original trial and earlier failed
compiler branches immutable. Do not claim that a correct saved artifact proves
stable understanding, or that a selected group would have shortened the run.

The next bounded development step is a Qwen consultation about the actual
resident-subtree misreading and use of checked saved work. It must not rescue or
retry this run. No automatic wording comparison, thought cap, working account,
history refactor or pinning policy is adopted from these results.

The full working goal remains active: sustained useful contributions on larger
