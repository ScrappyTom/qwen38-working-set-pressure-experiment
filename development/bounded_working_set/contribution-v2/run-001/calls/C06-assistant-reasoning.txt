```rst
.. exception:: MultilineContinuationError

   Raised when a valueless option, i.e. an option line that does not
   contain a value, is followed by a line indented deeper than the
   option line.  Such a line would be treated as a continuation of a
   multiline value, but a valueless option has no value to which the
   continuation could be appended, so reading is aborted and this
   exception is raised.

   Valueless options are only recognized when the parser is created
   with *allow_no_value* set to True; with the default of False, an
   option line without a value is not recognized as an option at all
   and the whole construct is reported as a :exc:`ParsingError`
   instead.

   :exc:`MultilineContinuationError` is a subclass of
   :exc:`ParsingError`, and therefore of :exc:`Error`.  Like
   :exc:`MissingSectionHeaderError`, it records the *source* passed to
   the read method in the :attr:`!source` attribute, the one-based
   line number of the offending line in :attr:`!lineno`, and the exact
   offending line, as read and including its line terminator, in the
   :attr:`!line` attribute.  The same three values are kept as
   :attr:`!args`, so the exception can be copied and pickled.  The
   inherited :attr:`!errors` list contains the offending
   ``(lineno, line)`` pair.
```
