## Review method and coverage

The reviewer directly read the complete initial native input, every subsequent
changed input field and appended event, every complete thinking field and final
answer, the exact tool results, and the next decision. Unchanged source and
history are checked by exact reconstruction and byte identities; an unchanged
copy is not an additional independent source. Input removal and all other copies
of relevant evidence must be inspected before attributing information loss.
Recorded acquisition, exact external storage, and delivery in a sent model input
are distinct facts. An unoffered next call is not an actor recovery failure.

review display may substitute its earlier artifact ID after comparing every
field and checking the displayed byte count and SHA-256. This display-only
reference is not model input and is not a semantic summary. All new fields,

thinking is always read separately, including repeated deliberation.
