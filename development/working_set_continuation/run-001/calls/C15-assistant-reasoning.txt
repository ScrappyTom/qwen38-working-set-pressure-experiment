~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

When an interpolated value references an option or section that does not
exist, calling :meth:`ConfigParser.get` (or :meth:`~SectionProxy.__getitem__`

The exception exposes the *option*, *section*, the raw *value* being

.. exception:: InterpolationMissingOptionError

   Raised when an interpolation reference cannot be resolved.  Attributes:

   * :attr:`option` -- the option being fetched.
   * :attr:`section` -- the section containing that option.
   * :attr:`reference` -- the referenced key that does not exist.
   * :attr:`args` -- a tuple of *(option, section, raw_value, reference)*.

Basic Interpolation
-------------------

With :class:`BasicInterpolation`, a reference has the form

``DEFAULT`` section:

.. doctest::

   >>> import configparser
   >>> parser = configparser.ConfigParser()
   >>> parser.read_string("[main]\nbroken = %(missing)s\n")

   ...     parser.get("main", "broken")
   ... except configparser.InterpolationMissingOptionError as e:
   ...     print(e.option, e.section, e.reference)

.. doctest::

   '%(missing)s'

Supplying the missing setting makes the lookup succeed:

.. doctest::

   >>> parser.set("main", "missing", "value")
   >>> parser.get("main", "broken")
   'value'

When an interpolated value refers to an option (or section, with extended

.. exception:: InterpolationMissingOptionError

   .. attribute:: option

      The option being fetched.

   .. attribute:: section

      The section containing that option.

   .. attribute:: reference

      The key that could not be resolved; for extended interpolation
      this is the ``section:option`` pair.

Basic interpolation
+++++++++++++++++++

With :class:`BasicInterpolation`, references use the ``%(name)s`` form
and are resolved against the same section and the ``DEFAULT`` section:

.. doctest::

   >>> parser = configparser.ConfigParser()
   >>> parser.read_string("[main]\nbroken = %(missing)s\n")

   ...     parser.get("main", "broken")
   ... except configparser.InterpolationMissingOptionError as e:

.. doctest::

   '%(missing)s'

.. doctest::

   >>> parser.set("main", "missing", "value")
   >>> parser.get("main", "broken")
   'value'
