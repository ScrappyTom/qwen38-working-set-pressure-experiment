## A new host defect is confirmed

Post-run inspection found that source deduplication changes the number of
displayed fragments as page length changes. Binary search assumes that shorter
pages are no more expensive; that assumption is false here. The original C03
rejected a read although pages 1855–1863 and 1855–1864 fit at 23,748 and 23,762
tokens. The latter supplies a previously absent line. The eight-case native
probe reproduces four original inputs/counts exactly and uses no model inference.

This is an engineering/qualification miss in the new host interaction. Do not
blame Qwen for C03's obstruction or describe every rejection as unavoidable
capacity. It does not establish what Qwen would have done with the corrected
page, or explain all later reading, speculative reasoning and the larger C15
edit rejection. The frozen outcome remains unchanged. The next mechanical
repair must account for source-fragment boundaries in page search and be
qualified offline before further exposure.
