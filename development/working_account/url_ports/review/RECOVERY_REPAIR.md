# Feedback before recent activity summaries

The uncoached attempt remains stopped without contribution at 9e95a08d. This
prospective repair is supported by its exact final input and admission trials;
it is not a resumed model trajectory or a retroactive change to the result.

The principle is to spend optional administrative presentation before losing
actual feedback. `AccountedSession` now first tries the complete ordinary view,
then removes oldest recent-activity rows one at a time when ordinary operation or
rejection feedback would otherwise not fit. It measures each complete proposed
native input against the same hard ceiling. `latest_feedback.recent_activity_limit`
records the reduced display limit. The complete activity archive, selected source
and saved results, account, current candidate, check applicability and exact
feedback are preserved. A later operation tries the normal recent view again.

Bulk source acquisitions retain their previous sizing rule; they cannot expand
their selected material by spending this fallback. Historical default sessions
also keep the old policy through a narrow feedback-admission hook. There is no
new token-counting task for Qwen, evidence eviction, summary generation, physical
context increase or reasoning cap. The shared tool reference already describes
recent activity as a bounded window rather than a complete archive; its wording
and the response grammar remain unchanged.

This is a bounded remedy, not a guarantee that every operation can fit. If current
state, selected evidence and required feedback exceed the ceiling even with no
recent rows, the existing explicit delivery/rollback stop remains. The host does
not select semantically sufficient evidence or force a narrower group on Qwen.
Selection, meaningful saved work and reliable termination remain model/system
evaluation questions.
