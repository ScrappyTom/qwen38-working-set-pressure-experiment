# Decision support in the three saved fixtures

These are CPU engineering fixtures. The selected objectives and scripted actions
are evaluator-authored; none is a new Qwen result. The original inputs, complete
replies, effects and artifacts remain in their run directories. Their existing
direct reading audits were consulted; the records below identify the support,
not a claim that replaying a script performs direct review.

| Fixture | Actual information in the saved input | Actual choice/effect | What this qualification asks |

No applicable feature check. | The full reply repeatedly reasons through parsing and writing, explicitly recognizes full source, then requests lines 1290–1360. The source read adds no new text. | Can a local objective persist above this same source without altering it, and survive serialization? No patch or parsing diagnosis is supplied. |

An absent-source edit is rejected; ordinary reacquisition then supplies exact source. |

The local objectives in the fixture script express purpose only. The source
selection, diagnosis, correct output, expected patch and future checker result
are not inserted. The release fixture's read of the library is researcher-chosen
using its real task path; it establishes feasibility, not autonomous discovery.

The exact C17 historical input is reproducible with the current base adapter.
The two older dispatch inputs predate already-committed operating-reference and
`source_extent_scope` changes. The qualifier separately checks: (1) projection of
the actual historical input preserves every original user field; (2) restoration
under the current base host changes only those identified baseline fields; (3)
the new adapter then preserves all current task/evidence/history fields and all
sampler settings. It does not call the older inputs exact current-host replay.

The fixture script initially used acquisition argument names for returned source
extents, and initially used the base dispatch task rather than its cumulative
continuation adapter. Both assumptions failed before qualification completed.
Using `returned_start_line`/`returned_end_line` and the actual saved-work adapter
corrected the script. No production rule, historical state, or test expectation
was weakened to hide those failures.

Direct inspection of the saved C12 final action also corrected an initial draft
of this table: C12 repairs the implementation first, not the test delimiter.
Its reasoning discusses both, but the final action determines what happened.

Inputs still include the full real task and optional account. The new objective
does not carry omitted private reasoning. Its usefulness and selection overhead
remain questions for a bounded model comparison, not findings from these fixtures.
