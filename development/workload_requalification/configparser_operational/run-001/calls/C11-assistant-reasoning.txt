
The `optional_flag` line matches the NV template with `value=None` (no value). So `cursect[optname] = None`.

Then the next line `    continuation` is indented deeper than `optional_flag` (indent_level is 0 for optional_flag, and the continuation line has indent_level > 0). So the code enters:

```python
if (cursect is not None and optname and
    cur_indent_level > indent_level):
    cursect[optname].append(value)
```

But `cursect[optname]` is `None` (not a list), so `.append(value)` raises `AttributeError`.

The fix is to detect this case and raise a `MultilineContinuationError` instead.
