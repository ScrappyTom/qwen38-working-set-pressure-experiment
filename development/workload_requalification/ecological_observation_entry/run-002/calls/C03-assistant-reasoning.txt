```python
def summary_graph_status(
    summaries: dict[str, SummaryNode],
    graph: SummaryGraph,
    address_maps: dict[str, AddressMap],
) -> dict[str, Any]:
    """Return deterministic freshness information for artifact and collection summaries."""

    stale_artifact_summary_ids = stale_summaries(summaries, address_maps)
    current_summary_ids = sorted(summary.summary_id for summary in summaries.values())
    graph_summary_ids = sorted(graph.artifact_summary_ids)
    collection_stale = bool(stale_artifact_summary_ids) and current_summary_ids != graph_summary_ids
    if graph.collection_summary is not None:
        collection_stale = collection_stale or sorted(graph.collection_summary.input_hashes) != graph_summary_ids
    missing_artifact_ids = sorted(artifact_id for artifact_id in address_maps if artifact_id not in summaries)
    return {
        ...
    }
```

Now let me identify the bugs:

**Bug 1: `collection_stale` logic**

Current: `collection_stale = bool(stale_artifact_summary_ids) and current_summary_ids != graph_summary_ids`

This uses `and`, meaning collection is stale ONLY IF both conditions are true: there are stale artifact summaries AND the current summary IDs differ from graph IDs.

But the task says: `collection_stale` should be true when:
- (a) any artifact summary is stale
- (b) the current artifact-summary IDs differ from the graph IDs
- (c) the collection's input IDs differ

So it should be `or` for conditions (a) and (b), and then (c) is already handled by the next line.

The fix: `collection_stale = bool(stale_artifact_summary_ids) or current_summary_ids != graph_summary_ids`

**Bug 2: `missing_artifact_ids` direction**

Current: `missing_artifact_ids = sorted(artifact_id for artifact_id in address_maps if artifact_id not in summaries)`

This lists address_maps that lack a summary (map without summary). But the task says: "missing_artifact_ids must list summary artifacts that lack an address map" - i.e., summaries that don't have a corresponding address map.

The fix: `missing_artifact_ids = sorted(artifact_id for artifact_id in summaries if artifact_id not in address_maps)`
