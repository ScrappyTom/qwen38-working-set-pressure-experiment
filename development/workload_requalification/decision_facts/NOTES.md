# Governance candidates from the ORBIT input review

These are development notes, outside actor inputs. The live trial is unchanged.

1. A prompt should describe the decision state it actually contains. A historical
   ledger can be correct while a completion field derived from it makes the current
   input unnecessarily difficult to interpret. Project host-known current facts
   without committing exposure before delivery. ORBIT C14 and C21 repeatedly
   reconcile newly delivered tails with an incomplete prior-coverage field.
2. Keep an effect identifiable after its full receipt leaves the prompt. A recent
   accepted edit's target path is an execution fact already known to the host. An
   opaque region reference alone can conceal which pending account statement the
   action superseded. Render the effect; do not silently rewrite the authored account.
3. A conservative evaluator screen is not the assignment. ORBIT's prospective
   script requires an explicit p0_page call and byte-identical completed name source.
   The actual assignment requires readable P0 orientation and preserved name behavior.
   The supplied root P0 plus a directory search can be a legitimate discovery route;
   behavior preservation requires execution/review, not merely a byte comparison.
   Preserve a failed mechanical screen and explain any separately assessed legitimate
   route instead of quietly changing the screen to count the preferred outcome.
4. An accepted edit and earlier pass do not settle a later dependency. C21's actual
   failure identifies changed name behavior after the policy mutation. Preserve that
   failed observation and evaluate subsequent correction, rather than counting the
   accepted mutation as successful completion of C or rewriting the earlier B result.

The first two points justify a narrow host correction. They do not justify a causal
token-saving estimate, compulsory account maintenance, or a new memory architecture.
The third is a constraint on our own assessment apparatus. The fourth is a boundary
the existing check/delivery machinery exercised correctly on the observed path.
