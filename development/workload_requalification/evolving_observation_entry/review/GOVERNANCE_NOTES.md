# Lessons to carry into governance after qualification

- A truthful partial return can still omit cheap, explicitly requested information.
  Measure complete alternative inputs before blaming the request or asking the
  model to perform capacity arithmetic. Completing small requested regions must
  retain all other accepted content and pass the same complete-input gate.
- The normal recent view must retain the mechanical facts needed to interpret the
  operation. File names alone do not say which regions a grouped read returned.
  Historical returned extent is not current visibility, editing authority, semantic
  understanding, or a proof that the task is complete.
- Model accounts should not be the only practical carrier of host-known execution
  facts. This run loses prior reading progress and repeatedly doubts unchanged
  code. That earns a bounded reporting question, not a new permanent transcript,
  claim graph, mandatory note, or automatic semantic summary.
- An accepted submission can meet host verification gates while missing user task
  obligations. Report artifact correctness, actual check consumption, temporal
  acquisition requirements and whole-task completion separately. Do not strengthen
  a checker silently to turn procedural research requirements into new gates.
- Check evaluator obligations against actual task language before exposure. The
  scripted route's convenient ordering is not automatically a task requirement.
  Preserve discovered evaluator mistakes and original results; publish a separate
  corrected interpretation without changing what the actor received.
- Complete valid replies and stable saved work deserve credit even when the
  trajectory is inefficient. Here every reply completes, recovery works and code
  survives; the failure is not physical-context exhaustion or a lost artifact.
- Custody-ledger coverage is an artificial procedural workload. Keep its cost and
  failures visible without treating them as the same evidence as a substantive
  investigation with changing semantic dependencies.
- A restored-state native counterfactual establishes input feasibility, not model
  behavior. A practical package may contain several independently justified host
  repairs, but cannot isolate their individual behavioral effects.
