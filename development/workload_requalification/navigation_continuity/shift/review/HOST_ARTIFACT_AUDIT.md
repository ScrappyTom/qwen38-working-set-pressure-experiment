## Artifact correctness and scope

The final helper computes max(shift.start, window.start) and
min(shift.end, window.end), returns zero for an empty/reversed intersection, and
otherwise returns elapsed seconds divided by 60. Reporting excludes nonconfirmed
shifts, omits nonpositive overlap, adds each positive amount by employee and
retains sorted mapping construction. This preserves the required invariant:
each employee's result is the sum of positive overlap minutes from every confirmed
row within the fixed-offset day. Overlapping rows remain additive, fractional
minutes remain representable, boundary-touching rows contribute nothing, and
shifts spanning either or both boundaries are clipped correctly.

The importer, Shift record, API, fixed-offset parsing, day-window construction,
README, example and package initializers remain unchanged. The original rejection
and offset paths therefore remain in place. The exact saved checker stdout is
2,546 bytes, fully captured, and contains twenty-four passing case records plus
the passing summary. Direct inspection confirms decoding/window, ordinary and
boundary reporting, additive rows, voids, fractions, offsets and invalid-input
cases. No extra checker execution was used for this audit.

**Compatibility limitation:** Qwen removes the existing source-documented
DayWindow.contains method rather than preserving it and changing only reporting.
Any external caller using that method would break. The original public task and
README identify daily_minutes as the public entry and do not explicitly promise
contains compatibility; the original checker never calls it directly. There is
no remaining contains caller in the candidate. Record this as unnecessary scope
and an unqualified compatibility change, not a retroactively invented failed
acceptance criterion. A future preservation requirement would need to be declared
before exposure. The earlier historical one-file repair is not the only accepted
implementation.

The intermediate C11 candidate had a missing contains call target until C12. That
is a deliberate untested intermediate edit in the stated two-file plan, not a
reported failing check or evidence of recovery. Final source eliminates the call
and satisfies the tested daily-report contract.
