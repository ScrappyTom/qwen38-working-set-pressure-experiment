Let me analyze the current state. I've read all the source files and understand the problem:

1. **The bug**: `DayWindow.contains()` in `windows.py` requires the *entire* shift to be inside `[start, end]`. For overnight shifts (e.g., 22:00 to 06:00 the next day), the shift spans two days, so it's never "contained" in a single day window. This means overnight shifts are completely excluded from both days' reports.

2. **The fix**: Instead of requiring the whole shift to be within the window, we need to compute the **overlap** between the shift and the window, and only count the overlapping portion.

The relevant code:
- `windows.py`: `DayWindow.contains()` → needs to be changed to compute overlap
- `reporting/daily.py`: `report_minutes()` uses `window.contains(shift)` and then adds `shift.duration_minutes` → needs to use overlap instead

The fix plan:
1. Replace `contains()` with an `overlap_minutes()` method on `DayWindow` that computes the overlap between `shift.start`/`shift.end` and `self.start`/`self.end` in minutes.
2. In `report_minutes()`, replace the `contains` check with overlap computation, and only add the overlapping minutes.

Let me think about the overlap calculation:
- overlap_start = max(shift.start, window.start)
- overlap_end = min(shift.end, window.end)
- if overlap_start < overlap_end: overlap = (overlap_end - overlap_start).total_seconds() / 60.0
- else: overlap = 0.0

This handles:
- Overnight shifts: a shift from 22:00 to 06:00 the next day will have partial overlap with each day
- Shifts entirely within a day: full overlap (same as before for `contains`-true case)
- Shifts entirely outside: zero overlap (correctly excluded)
- Void shifts: still excluded by the status check
- Fractional minutes: handled by using total_seconds() / 60.0

```python
    def overlap_minutes(self, shift: Shift) -> float:
        """Minutes of the shift that fall within this window."""
        start = max(shift.start, self.start)
        end = min(shift.end, self.end)
        if start >= end:
            return 0.0
        return (end - start).total_seconds() / 60.0
```
