# Host, information path and artifact audit

## Custody and transition results

verify_run.py restores every one of 53 starting/after/final checkpoints through
the qualified adapter, reproduces exact snapshots, validates all reply bytes and
decoded actions, and checks their recorded effects. It verifies 1,236 public
artifacts, 985 bound sources and 1,103 custody records. Every displayed source
extent is compared with its actual candidate bytes (103 presentations).

All 49 receipts with a following call arrive. This includes C43's accepted account
and rejected read, C63's account/edit/automatic failed check, and ordinary acquired
bodies. The final C64 account/read returns are recorded and admitted, but not
received by another model call. The run's ending allowance is 64/64 requests and
152/197 operations; action-only check-opportunity metrics are not proof that an
adaptive correction and submission fit the remaining requests.

No new implementation exception, lost observation, stale-guard bypass, missing
nonterminal receipt or runtime truncation is established. This is a scoped result,
not certification of every host path. Native preparation remains separate from
the live outcome. The earlier failed restoration audit and its prospective fix
remain preserved, including the fact that our adapter repeated a known pattern.

## Two recovery arrangements, two different outcomes

C44 receives a complete 6,869-token control view after a capacity read rejection
and replaces the broad group with test lines 2050–2210. That actual action restores an
ordinary input. It demonstrates model-chosen recovery on the corrected host.

C64 receives complete failed-check feedback in a 12,536-token control view. The
source group remains designated but all its bodies are omitted. In particular,
the just-edited test is absent, and the companion patch receipt supplies intervals
without the applied diff. Under the actual source guard, the actor needs current
source before another edit. Its read of lines 2200–2360 is therefore appropriate.
The result fits at 11,478 tokens with failed criteria retained; no request remains to use it.

This is a real presentation-policy cost. Correct feedback delivery does not show
that the failure and current correction target were available together. A future
host qualification should test that co-presence using the actual edited region,
without supplying a repair or treating all bulk selected evidence as mandatory.
No counterfactual native token count or successful correction is claimed here.
