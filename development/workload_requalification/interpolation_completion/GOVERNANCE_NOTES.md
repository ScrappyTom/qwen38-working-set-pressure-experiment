# Lessons to reconcile into project governance

These notes come from the closed completion002 and its actual inputs, full outputs,
saved effects and independent artifact probes. They do not rewrite earlier scores
or establish a general model failure rate.

1. **Keep the correction target with its feedback when feasible.** Delivering a
   truthful check in a recovery view can still leave the current artifact absent.
   A reread then follows from the host's source guard. C64 is such a case. Treat
   this as an information-arrangement cost, not evidence that the model forgot
   source still visible. Qualify an explicit bounded policy; do not promise that
   arbitrary selected material, arbitrary feedback and the target always fit.

2. **A class declaration is not its inherited behavior.** C63 correctly reads the
   missing-reference constructor but invents an uninspected base implementation
   and changes its diagnostic expectation. Distinguish a definition never acquired
   from evidence evicted or misread. Preserve missing dependency questions rather
   than promote a plausible default into an inspected fact. Mechanically available
   ownership/base information can aid discovery without certifying semantics.

3. **An account is not a freshness guarantee.** Twenty accepted updates preserve
   reading plans, drop useful coordinates, repeat stale counters, and eventually
   record a wrong behavioral conclusion. The host correctly records authorship
   before companion operations; this does not make the resulting account useful
   or true. Do not require more notes or silently rewrite them as the remedy.

4. **Validate the saved contribution, not the best private draft.** C63 contains a
   correct message expectation early and a wrong one in the final patch. Only the
   actual complete reply is executed. A 26,116-token response that eventually
   returns an edit is different from a context-exhausted empty final. Both cost
   and saved correctness matter; neither elapsed generation nor a valid action
   establishes sound reasoning throughout.

5. **Ordinary failure masks later coverage defects.** The check appropriately
   reports three real errors and blocks fault credit. Independent probes reveal
   wrong diagnostics and weak exact-class assertions after those errors are
   removed. Keep such probes separate from the actor artifact and full acceptance.
   Do not strengthen scores using a reviewer-corrected variant.

6. **Carry unresolved process dependencies forward.** The earlier source-context
   audit already identified the unused outline and omitted ownership relationships.
   A consultation was prepared but not dispatched. Transferring newer general host
   improvements was a legitimate development question, but did not settle that
   earlier one. A successful scripted route and extensive custody qualification
   must not repeatedly substitute for testing the actual information decision.

7. **Reuse known apparatus repairs before exposure.** Our new adapter initially
   repeated an already-solved numeric-versus-JSON address comparison defect. The
   final preparation audit caught it before inference. Preserve that failed
   preparation, reuse the existing typed comparison, and qualify restoration of
   real later checkpoints. More passing tests are not a substitute for testing
   the previously missing boundary.

8. **Keep opportunity and cost scopes explicit.** Remaining operations do not
   imply remaining adaptive model decisions. At closure, 45 operations remain but
   no requests. Action-only check-opportunity fields state their restricted basis;
   reports must not turn them into feasible correction journeys. Include prior
   dispatched attempts, unknown costs and preparation/review costs honestly.

Retain exact identities, guarded effects, observation preservation and the working
recovery core. The earned next work concerns a usable correction context and the
already-deferred discovery question. No new archive, mandatory memory policy,
global thinking change, weakened task contract or unchanged retry follows from
this outcome.
