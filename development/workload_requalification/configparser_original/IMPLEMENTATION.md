# CPU adapter qualified; native and model gates remain open

The bounded implementation is confined to this directory. No shared host or
frozen task/source was changed, and no model, GPU or native runtime request was
sent. There is no launchable execution manifest or new runner in this tranche.

`configparser_task.py` supplies the verified original ten-file candidate, exact
task, explicit 1 MiB file allowance, public-only check, empty selection/history/
account entry, 40 requests/80 operations and existing incident/session annotation.
It uses the common CoherentDiagnosticSession and ObservationStore. Edits do not
trigger checks, and the reply schema does not offer `check_after` or tests/examples
scopes. The source form and working-set operations remain those of the current
host. The generated operating reference describes this specific check policy.

The adapted checker has SHA256
`db034e5d1501d1c01bc2fd5c00a47c90e22a358334eb0603bee4b2e2906c1b45`.
It preserves the original constants, suite selection, contract assertions,
added-ID calculation and acceptance predicates. Only the final reducing formatter
and discarded suite-runner stream are changed: full failure records, added IDs
and exact runner text are emitted to the capture layer before projection. The
original checker remains separately pinned and executed for equivalence.

`configparser_reports.py` interprets this identified shape. Its five criteria
separate upstream tests, independent contract, current edited tests, detection
against the original parser, and the documentation declaration. The old-parser
comparison uses current added tests with original implementation; an expected
failure is not presented as another current-library failure. The report does
not claim prose accuracy or intact old test text. Both require direct review.

The immediate/standing report preserves the first useful current failures and
true shown/remaining counts. Criterion inspection includes bounded diagnostic
samples; raw inspection recovers the complete captured report and runner text.
UTF-8 and serialized display size are checked before projection, so escaping
does not silently make the nominal text allowance a larger output allowance.
Unsupported shapes and invalid Unicode scalars retain raw access and actual
execution status without inferred suite results.
