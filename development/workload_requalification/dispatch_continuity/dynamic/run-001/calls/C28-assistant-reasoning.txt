======================================

The ``functools.singledispatch`` decorator supports registering handlers for
unions of types.  A union handler is invoked whenever the first argument's
class matches (or is a subclass of) any member of the union.  Both PEP 604
syntax (``A | B``) and ``typing.Union[A, B]`` are accepted.

Union registration
------------------

>>> import functools
>>> from abc import ABC
>>>

...     pass
>>>

...     return "default"
>>>

... def union_handler(x):
...     return "union"
>>>
>>> handler(42)
'union'

The registered implementation is stored once per union member, so the
dispatcher resolves the match through the normal method-resolution path.

Late virtual registration
-------------------------

A class that is registered as a *virtual* subclass of a union member after
instances have already been dispatched will be picked up on the next dispatch
call, without any explicit cache-clear:

>>> class Payload:
...     pass
>>>
>>> p = Payload()
>>> handler(p)

>>>
>>> PluginBase.register(Payload)
>>>
>>> handler(p)
'union'

The dispatcher tracks the ``abc`` cache token internally; when the token
changes (as it does when ``register()`` mutates the ABC cache), stale
entries are discarded transparently.
