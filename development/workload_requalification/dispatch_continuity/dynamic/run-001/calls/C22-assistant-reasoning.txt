The bug: when `cls` is a union type (e.g., `PluginBase | int`), `hasattr(cls, '__abstractmethods__')` checks the union type itself, not its members. A union type like `PluginBase | int` doesn't have `__abstractmethods__` - only `PluginBase` does. So `cache_token` never gets set for union registrations that include ABCs.
