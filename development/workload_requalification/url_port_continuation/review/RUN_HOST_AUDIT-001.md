## Concrete interface burden: addressed extent versus visible body

The host offers `replace_region` and literal SOURCE to avoid old-text copying
and JSON escaping. Current bodies appear in one authoritative
`working_set.sources` list; feedback carries references rather than duplicated
bodies. Reads merge overlapping selected extents. Rejected ambiguous patches
also return narrow region addresses. The resolver supports such an address
when the complete addressed extent is already covered by visible current
source; the address itself supplies no bytes or editing authority.

This relationship is not presented consistently enough on the observed path.
The main search description says: "A region address is not visible source:
read or work_on_exact must actually deliver its body before editing." C30
quotes this sentence and reasons that the first match reference is unusable
because it differs from the merged visible 125–260 body's reference, although
the complete 133–140 addressed text is inside that current visible body. The
additional rejection reference says an address *alone* grants no authority,
and `replace_region` requires the whole region to be visible. Those latter
statements fit the implementation, but do not make the containment relationship
explicit. C27–C29 also repeatedly consider only the broad merged body as their
replacement option despite narrow addresses in immediate feedback.

The earned concern is therefore the operational description of existing
address/body containment, not a broken resolver, absent source or a need to
weaken guards. A post-run correction could state that an already displayed
current-source range may cover a returned address; another acquisition is
needed only when its complete current bytes are not shown. This is a proposed
truthful clarification of the implemented rule. It is not a demonstrated cure
for all deliberation or a chosen change to the completed run.

C21/C22 show a related construction burden: a seven-line semantic correction
was expressed as a whole-method old/new patch, requiring exact source spelling
through serialized strings. A smaller region route existed but the then-current
visible body reference spanned neighboring methods. Later narrow addresses
were available but remained hard to relate to the merged body. These are
observable representation and granularity costs. The run does not isolate
their complete causal share or justify changing payload format and reasoning
policy together and assigning an improvement to either one.
