## The minimum defensible E20 barrier

The original task explicitly says: before the first mutation, make an exact
complete read of every named path; this is a required audit deliverable. Unlike
E19, one nonempty source excerpt per path cannot satisfy the mechanical part.
The minimal E20 rule is continuous exact delivered coverage from line 1 through
the true EOF of each of the eleven files.

Use a version-bound union of actual delivered line intervals. For each path,
derive the true line count from its exact current file bytes, validate every
credited range/content/fingerprint through the existing current-source route,
and merge adjacent or overlapping ranges. Require the union to cover every
line; seeing the beginning and EOF with a gap is insufficient. Do not combine
ranges from different file fingerprints. A changed identity invalidates earlier
coverage for that file before the first mutation.

Credit occurs on dispatch, not acquisition, rendering, sizing or storage. A
complete historical source result may count only when the existing validator
establishes exact unchanged current bytes. An outline, handle, account, search
address, partially recovered serialized record or recovery inventory does not
count. An empty page beyond EOF cannot complete a nonempty file. All eleven
original files are nonempty, so this entry does not require inventing a generic
empty-document policy.

Keep cumulative coverage separate from current edit eligibility. Explicit
release of an unchanged body should preserve its real prior coverage. A later
edit still needs its exact current target source in the actual decision input.
The actor chooses what to retain, release and reacquire; the host neither ranks
semantic relevance nor supplies a compact researcher group.

Before either guarded mutation form, reject any missing coverage with truthful
paths and missing line intervals, preserving the public proposal and candidate.
Rejected edits leave the inspection window open. The first accepted mutation,
including a cosmetic edit, closes it and binds the predecessor, successor and
coverage witnesses. Accounts and checks do not replace this boundary. Retain
ordinary guards and the actor-requested current public pass requirement.

A small resident inventory can expose each path's exact identity, total lines,
covered/missing intervals and recorded first-mutation status. Detailed delivery
witnesses belong in stored material and reconstruction/replay. Bound witness
growth using this task's finite paths, line counts and request allowance; do not
put every historical source carrier into each prompt. Preserve the E19 timing
clarification: displayed accumulated status covers previous dispatches; exact
source shown in this input gains credit when it is dispatched and needs no
extra read solely to obtain credit.

This enforces mechanically complete exposure, not comprehension or substantive
audit. Independent review must still assess whether the model used the sources,
preserved required behavior and formed supported conclusions. A new accepted
edit would partly demonstrate host enforcement; it would not independently
prove the model remembered to inspect every file unaided.
