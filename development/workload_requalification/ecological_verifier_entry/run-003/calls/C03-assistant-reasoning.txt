- Any absolute path (not just absolute + `..`)

```python
def _safe_relative_path(path_or_name: str) -> PurePosixPath | None:
    normalized = path_or_name.replace("\\", "/")

        return None

        return None
    return path
```

- Empty/whitespace-only paths (via the `if not normalized` check)
- Absolute paths

The issue: `max(1, max(timeout, MAX_COMMAND_TIMEOUT_SECONDS))` - this always returns at least `MAX_COMMAND_TIMEOUT_SECONDS` (60), because `max(timeout, 60)` is at least 60, and then `max(1, 60)` is 60. So it clamps to minimum 60, not 1.

The correct clamping should be: clamp to the inclusive range 1..MAX_COMMAND_TIMEOUT_SECONDS:
```python
def _bounded_timeout(value) -> int:
    try:
        timeout = int(value)
    except (TypeError, ValueError):
        timeout = 20
    return max(1, min(timeout, MAX_COMMAND_TIMEOUT_SECONDS))
```

This clamps timeout to [1, 60]:
- If timeout < 1, return 1
- If timeout > 60, return 60
- Invalid values default to 20, then clamp (20 is in range so stays 20)
