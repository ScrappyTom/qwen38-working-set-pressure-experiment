# Lessons to carry into governance

1. A common page proportion is a sizing heuristic, not a guarantee that small
   requested interfaces are usable. Measure complete requested regions beside the
   admitted bulk page before making the model reacquire a missing line. Keep the
   counting in the host and retain exact current-source eligibility.
2. Recent activity should preserve the mechanical fact needed to distinguish
   repeated operations. Here, file names alone erased the difference between
   acquisitions1-58 and59-114. Project actual returned extents from the archive;
   do not turn them into current visibility, semantic reading or task completion.
3. Useful metadata still consumes capacity. Qualify its complete-input cost,
   rejection path and selection transition. This package shortens some bulk pages
   relative to the old renderer. Report that cost alongside the repaired omission.
4. Hold reporting constant when qualifying a paging refinement. Otherwise a new
   smaller bulk allocation could conceal displacement and appear to prove a free
   completion. The five native comparator cases preserve every admitted bulk byte.
5. A scripted route and exact replay establish mechanics and delivered information,
   not the next model decision. Keep the E18 finite failure and our earlier
   overstrict ledger-order evaluator unchanged. Neither is rescued by this package.
6. Historical experimental tests can become stale as intended interfaces evolve.
   Preserve their failure, establish whether it predates the current change, and
   report the actual qualification scope. Do not alter current safeguards merely
   to satisfy an old claim that only one wording field ever changed.
