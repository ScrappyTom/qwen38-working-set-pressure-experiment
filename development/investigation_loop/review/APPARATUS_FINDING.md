interface treatment. The candidate is an owner-controlled donor with one injected
old-map return; it is not a newly discovered production fault. The task and
initial orientation omit the diagnosis, reading list, repair and a pre-executed

prepatch check that reveals the answer, but the source and simple injection still

behavioral contract rather than merely comparing with donor bytes: eight
assertions cover accepted application, independently rebuilt-map extraction,
current function reopening, the unchanged neighbor, old exact-reference

propagated map/version match is also printed and true; it is not an additional
assertion. The original file's offline-probe docstring is preserved provenance;
the manifest and runner bind that exact file as the live public check.

The check constructs previews directly rather than testing every library entry
point. Its extraction cross-check uses the same library's independent map build,
not a separately implemented extractor. Passing it is evidence for its concrete
cases, not all reference/edit behavior. Direct final-source comparison confirms
that only the map-return line changes and that hash-rejection logic remains
intact. Both repairs happen to equal the donor, but that equality is not the
acceptance criterion. There is no hidden grader or withheld-test claim.

The library under repair and the operating host both use edit/reopen vocabulary.
After mutation the original incident description remains twice in the input;
