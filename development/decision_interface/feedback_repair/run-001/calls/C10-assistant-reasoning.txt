```python
@property
def _hostinfo(self):
    netloc = self.netloc
    _, _, hostinfo = netloc.rpartition('@')
    _, have_open_br, bracketed = hostinfo.partition('[')
    if have_open_br:
        hostname, _, port = bracketed.partition(']')
        _, _, port = port.partition(':')
    else:
        hostname, _, port = hostinfo.partition(':')
    if not port:
        port = None
    return hostname, port
```

So for `http://host:/` → netloc = `host:` → `hostinfo = 'host:'` → `partition(':')` → `('host', ':', '')` → port = `''` → None.

For `http://host:0/` → port = `'0'` → not empty → stays as `'0'`.
