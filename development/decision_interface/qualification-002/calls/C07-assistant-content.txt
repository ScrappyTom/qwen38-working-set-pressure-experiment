URL Parsing
-----------

Port access and validation
--------------------------

For both :func:`urlsplit` and :func:`urlparse`, an absent or empty port
produces ``None``. Zero and 65535 are accepted boundary values. For an
otherwise valid URL, constructing the result does not validate the port:
accessing its ``port`` attribute performs that validation. The port must
contain ASCII decimal digits and be in the inclusive range 0 to 65535.
Negative and noninteger values fail the decimal-format check. These rules
also apply to ASCII byte URLs; a non-ASCII digit in a text URL is rejected.

   >>> from urllib.parse import urlsplit, urlparse
   >>> [urlsplit('http://example.test' + ending).port for ending in ('', ':', ':0', ':65535')]
   [None, None, 0, 65535]
   >>> too_large = urlparse('http://example.test:65536')
   >>> too_large.port
   Traceback (most recent call last):
       ...
   ValueError: Port out of range 0-65535
   >>> negative = urlsplit(b'http://example.test:-1')
   >>> negative.port
   Traceback (most recent call last):
       ...
   ValueError: Port could not be cast to integer value as b'-1'
   >>> letters = urlparse('http://example.test:invalid')
   >>> letters.port
   Traceback (most recent call last):
       ...
   ValueError: Port could not be cast to integer value as 'invalid'
