## What the run establishes

- Qwen chooses its own search, implementation read and source-group replacement
  from the real recovery view. It returns to ordinary work and makes guarded edits.
- A wrong empty-port expectation becomes saved provisional work, receives an actual
  failing check, and is corrected. A later explicit fault criterion correctly leads
  to an exception-class assertion. The previous fault-outcome polarity confusion
  is not reproduced on that action.
- The checker accepts the test contribution while its bytes loop still lacks the
  exact-class assertion. An independent bytes-only subclass fault passes all 73
  saved tests. A text-only or global subclass fault fails. Correct check bindings
  do not make this evaluator complete for the task's stated coverage.
- Three documentation patches are rejected. Each old fragment exactly matches
  displayed text but also occurs outside the displayed extent. The host knows the
  two matches and returns only a combined no-match/multiple-match/no-change message.
  C15 repeats C14's exact anchor while believing it differs. This is a concrete
  feedback omission, not inaccurate copying of visible source.
- C16 uses the literal SOURCE channel and replaces the displayed region. Its 19
  new executable examples pass. The public check fails documentation preservation:
  existing text is rephrased and the missing terminal LF joins the replacement to
  the next unselected line. The host preserves the rest of the document correctly.
- The final account/edit/check have no subsequent model invocation. Qwen therefore
  never receives that public failure. All 30 nonterminal receipts are represented
  in their actual next inputs; all displayed current-source bytes match their
  versioned candidates. No result-delivery or physical-capacity stop occurs.

The test method covers useful boundaries and exact arguments/messages, and all
original tests and implementation remain unchanged. The docs are useful partial

Transport qualification remains separate: 23 focused tests, nineteen native
delimiter/final cases, and four endpoint smoke calls costing 59.592 seconds. Both

established exact LF preservation when emitted; it did not qualify reliable LF
construction by the actor. The live replacement now shows why that distinction
matters for region boundaries.

## Development decision

Keep the response repair and exact archive/guards. Do not repeat this configuration
unchanged or describe its scoped tests pass as full task correctness. The next
earned work is host-side: useful primary diagnostics and truthful displayed counts;
baseline-qualified, path-sensitive check claims; precise ambiguous-edit feedback;
explicit preservation requirements; clear excerpt/file scope; and a declared safe
line-boundary contract for region replacement. Qualify those at these exact states
before another expensive exposure. Do not silently add a terminal newline to this
historical artifact or loosen its frozen checker.

This package is closed. Its unused operations do not authorize another request.
