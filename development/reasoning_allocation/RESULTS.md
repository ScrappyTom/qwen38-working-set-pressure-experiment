## Interpretation boundaries

This is a controlled instruction-policy comparison on two seeds of one reused
task. Medium omits the embedded template's extra validation/alternatives paragraph;
thinking remains enabled and uncapped. Native input is 38 tokens shorter per medium
invocation. The intervention does not directly measure internal reasoning effort.
The earlier unusually long successful run is motivation, not a selected control.

The actor receives the same task, source, saved history, tool reference, reply
constraints, executor and budget policy within each pair. Every attempt starts
with an empty selection and a fresh owned runtime. No reviewer coaching, helper
inference, retries or cross-attempt results enter its inputs.

The host enforces exact-source edit eligibility and a passing check matching both
current candidate and checker definition before accepting submission. The requested
edit/check sequence and use of its actual feedback are model behavior; accepted
submission alone cannot establish independent verification discipline.

Two host limitations deserve separate prospective correction. Contained source
pages can be shown twice inside merged selection and immediate feedback. Also,
the displayed 24-operation allowance omits the independently enforced 16-request
limit. Actual planning refers to the larger visible remainder. These observations
do not establish how corrected inputs would change the four outcomes. No source
or budget is changed during the comparison. See [host audit](HOST_PATH_AUDIT.md).

Long responses mix useful test design, ungrounded assumptions about unread code,
repeated decisions and action-format construction. The full thinking and actual
inputs are inspected in the [direct audit](DIRECT_TRANSCRIPT_AUDIT.md). Neither
all long thinking nor all rereading is classified as waste. A question considered
in thinking is not counted as an executed operation or a proven cause.

This comparison exercises an input-capacity stop and a narrow generation margin.
It does not demonstrate continuity across a controlled context externalization
treatment. Prior thinking is omitted from each next input; repeated analysis is
not automatically evidence lost at a pressure boundary. Medium's short successful
edit response does not justify shrinking the reserve for other work; xhigh's
ordinary edit response substantially exceeds it.

The recurring encoding deliberation is concrete development evidence worth keeping,
not an automatic mandate to redesign the patch format. If a presentation remedy
is proposed, consult Qwen on the actual difficult input outside a run before
settling it, with retaining the interface still a valid outcome. Mechanical truth
about source visibility and enforced allowances needs no preference vote.

Reported request time includes the actual model requests; loop time includes their
task-loop surroundings. Runtime startup, preparation, offline replay and reviewer/
Codex inference cost are not included in those loop totals. Reviewer effort is
not separately metered and must not be treated as zero or as an all-in cost claim.
