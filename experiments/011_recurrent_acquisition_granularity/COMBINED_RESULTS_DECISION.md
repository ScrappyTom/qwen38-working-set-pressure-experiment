## What the combined evidence says

### 1. Maximal paging solves one real but conditional failure mode

The causal pair remains IOTA/173205. The actor knew each required file ended near line 198 but selected 100-line L0 pages. Two extra read/history entries consumed enough headroom to prevent the next boundary call. L1 removed only that physical choice and completed correctly.

The other three pairs show the boundary of the mechanism. When L0 chose 200 or 250 lines, both contracts transferred the exact required file in one action and paging conferred no semantic or closure advantage.

### 2. The paging change is not the main project result

Across the seven completed Phase-C paths now available from the primary partial plus supplement, every path selected current `OBS-0005` over stale `OBS-0002`, reopened the exact current marker, made the correct bound mutation, passed hidden grading, and submitted.

The larger result is that the minimal controller repeatedly preserved purpose and candidate-bound evidentiary continuity across two context reconstructions. Physical paging is a small reliability guard around that controller, not a new memory architecture.

### 3. No read suppression or richer metadata is earned

The completion pair succeeded without duplicate-read suppression, caching, semantic ranking, summaries, relationship metadata, or host-selected relevance. It also showed no redundant read. The prior extra wire confirmations were model-policy variation and did not block closure. Adding a suppression layer would increase system complexity without a demonstrated outcome-level need.

### 4. Thinking-mode comparison is not warranted

All paths used the same server-enforced low bounded reasoning. Saved private reasoning identifies why each read was chosen. The important failure and neutral cases are explained by the physical line-count decision, not by opaque or missing rationale. Changing thinking policy would confound the controller and is not earned by these transcripts.

## Decision

Deterministic maximal exact paging remains narrowly promoted as the default physical transfer rule for future bounded-context work. The reason is mechanical and limited: it removes a demonstrated low-value page-size decision while preserving exactness, actor choice of path/start point, replay, and semantic neutrality.

Experiment 011 does not earn a new representation feature or another paging replication. The missing pair adds a third neutral case and reinforces that the mechanism's benefit appears only when actor-selected paging would fragment an already-chosen exact extent.

The next high-ROI research question is broader recurrence and validity, using the same minimal controller and maximal paging without adding suppression or semantic memory. A future study should test new task geometries where governing source and dynamic observations change across repeated boundaries. It requires a fresh specification, bank, and owner authorization; it is not started automatically here.
