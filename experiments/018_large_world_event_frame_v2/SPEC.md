# Experiment 018 — Fresh large-world signal-bearing event frame

## Question

Can the qualified V2 signal-bearing event plane support a long, fresh,
large-world coding step under a 25,000-token reconstructed ceiling when a
50,176-token resident control keeps the same exact payload bodies inline?

This is a whole-controller viability study, not a pure context-size estimate.
Both conditions use exactly one event plane at the same prompt location. There
is no parallel chronology or receipt ledger.

## Conditions

`R50` retains every exact action payload and result body in the single V2 event
plane until the physical 50,176-token context refuses the next request.

`X25` begins from the byte-identical event plane. At the first authentic point
where the next fully resident request exceeds 25,000 tokens but remains under
the physical context, the state forks. X25 then moves the oldest bulky payload
bodies out of residence, only as needed to admit the next request. It retains
the complete readable action/result signal and exact `EVT-*` / `RES-*` reopen
addresses.

The model selects the file, observation, result, or event to reacquire. The
host selects no semantic relevance and performs no summary, ranking, caching,
suppression, or duplicate substitution.

## Fresh geometries

- `E18-SOURCE-LANTERN`: evolving exact source policy plus required large
  ledgers and two mutations that must preserve old and current policy values.
- `E18-OBS-HARBOR`: stale/current candidate-bound observation identities,
  exact reopen, repeated use of the current marker, required large ledgers,
  and two mutations.

Each family runs under seeds 173205 and 223607. Each shared prefix is executed
once. The two branches inherit the exact candidate, tool state, event prefix,
and observation custody at the authentic pressure point.

synthetic Python geometries. It is not evidence for semantic summaries,
relationship graphs, learned retrieval, arbitrary repositories, or strategic
memory. A negative model outcome does not authorize a new feature; transcript
evidence must identify the failing layer first.
