# Experiment 019 Results and Decision

## Formal result

**Infrastructure-stopped; paired experiment unscorable.**

The authorized run stopped during cell 2 after 13 exact HTTP completions. No
R50/X25 treatment boundary was reached, no treatment branch executed, and the
observation family was never exposed. The run is not evidence for or against
the comparative ecological hypothesis.

## Usable behavioral evidence

One seed completed the exact owner-controlled source repair: four mandated
current-source reads, two exact correct patches, a passing public check bound
to the current candidate, accepted submission, and passing post-seal hidden
grade.

The second seed correctly diagnosed both defects in private reasoning but
emitted a strict no-op patch. That action exposed an infrastructure defect and
did not receive the bounded rejection/continuation it should have received.

## What was learned

The controller was not falsified, but it was not materially exercised beyond
its pre-pressure resident event plane. The task named all four files and
specified both exact semantic corrections. Qwen used ordinary exact reads,
not P0 or reopening, and completed at 16,265 prompt tokens.

An ecological fixture therefore needs two independent qualifications: it must
require grounding in real owner source or observations, and its necessary
correct path must cross the context treatment before completion.

The no-op is separately diagnostic. The actor possessed and stated the right
information but failed to serialize the intended mutation. More metadata would
address the wrong problem. The correct host behavior is a bounded mechanical
rejection, which is now implemented.

## Prospective host decision

Promote only these infrastructure corrections:

- reject patches that do not change exact bytes;
- permit idempotent reuse of an already-custodied identical candidate snapshot;
- fail on same-address byte mismatch;
- count actual request/response artifacts in infrastructure-stop receipts;
- label pre-boundary checked submissions accurately.

They do not select relevance, suppress actions, repair model output, or change
the retained information architecture. The consumed measured run will not be
rerun.

## Research decision

Preserve Earned Controller V1 and canonical payload identity as mechanically
qualified but **not live-validated by Experiment 019**. Do not infer anything
new about resident versus externalized payloads.

A future fresh ecological study is justified only after scripted qualification
proves that the correct necessary path authentically crosses 25k before
completion without padding, both branches begin byte-identically, acceptance
semantics are clear, a full correction cycle remains, no-op/revert paths are
mechanically handled, and the observation path truly requires selecting and
reopening signal-bearing exact evidence.

No successor study is automatically authorized.

## Bottom line

> Exact task plus exact source was sufficient for one grounded repair. The
> first run stopped on a custody/no-op defect before any context treatment,
> and the source fixture itself was too direct to force that treatment.
