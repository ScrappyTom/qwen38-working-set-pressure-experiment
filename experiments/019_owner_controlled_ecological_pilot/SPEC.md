# Experiment 019 Specification

## Question

Can Earned Controller V1 perform useful owner-controlled code repairs after
authentic pressure, while a same-signal resident-body controller approaches or
reaches physical context exhaustion?

## Conditions

- `R50`: one signal-bearing event plane; exact event payload bodies remain
  resident under the physical 50,176-token slot.
- `X25`: the same plane and signal; the oldest exact bodies move to external
  custody only as required by the exact 25,000-token guard.

Before the first authentic pressure boundary, each pair is byte-identical.
Both conditions use the same P0, tools, canonical payload provenance, 512-token
private reasoning allowance, sampler, actor, and call schedule.

## Fresh owner-controlled tasks

`E19-SOURCE-REOPEN` repairs two injected regressions in the exact reopen
pipeline. Inclusive source ranges and strict truncation semantics are stated
verbatim; no hidden semantic interpretation is required.

`E19-OBS-SUMMARY-GRAPH` requires Qwen to choose a current candidate-bound
verifier observation, reopen its exact body, and repair two status regressions.
The observation directory carries readable action/target/candidate/hash/size
signal. Handles alone are not treated as evidence.

The candidate is a 25-module bounded snapshot from the owner-controlled
Addressable Information Layer. Exact production donor bytes remain under
`fresh_bank/donor_snapshot`. The production package initializer imports a 34 KB
runner that exceeds the frozen 24 KB candidate-file bound, so both conditions
receive the same neutral initializer. The adapter contains no task semantics.

## Execution

- two cases × two seeds × two branches;
- one attempt per branch;
- zero retry, repair, rescue, or cross-cell history;
- 24 total action opportunities per paired trajectory;
- strict JSON, exact candidate/file/check bindings;
- maximal whole-line reads;
- response sealing before evaluator access;
- no automatic successor.

The tasks do not disclose an ideal path. Offline qualification proves the
known-good donor fits. Fixture design leaves room for a complete
`check → patch → recheck → submit` correction cycle after a reasonable direct
path.

Every saved prompt, private reasoning field, action, and result must be read
directly before behavior is diagnosed.

## Historical execution status

The authorization was consumed by one infrastructure-stopped run. It ended
after 13 saved completions, before any R50/X25 branch, and is unscorable as the
specified comparison. The specification remains the prospective contract; it
must not be read as a claim that all eight branches executed. See
