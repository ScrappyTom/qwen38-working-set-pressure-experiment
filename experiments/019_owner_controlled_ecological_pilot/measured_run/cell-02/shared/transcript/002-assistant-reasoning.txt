- We want lines 5 through 10 (inclusive), which is indices 4 through 9.

- But the current code does `lines[unit.start_line - 1 : max(unit.start_line - 1, unit.end_line - 1)]` which gives `lines[4:9]`, missing line 10.

So the fix for `exact_text_for_unit` is to change `unit.end_line - 1` to `unit.end_line`.
