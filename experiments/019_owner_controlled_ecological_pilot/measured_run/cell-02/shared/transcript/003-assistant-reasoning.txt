This is wrong because:
- `unit.end_line - 1` would exclude the last line (since Python slices are exclusive at the end)
- The correct slice for inclusive start/end is `lines[start_line - 1 : end_line]`

So the fix is: `lines[unit.start_line - 1 : unit.end_line]`
