# Experiment 007: recurrent bounded-pressure continuity

## Question

Can the exact minimal controller that passed one authentic 25k transition
preserve purpose, source evidence, observation validity, and closure through a
second prospective pressure transition?

## Frozen treatments

- **C50-R1:** exact append-only control under the physical 50,176-token slot.
  It is expected to become a capacity reference during or after Phase B.
- **T25-R1-recurrent:** fresh 25k context after each eligible boundary, with
  exact task, current candidate/P0, the latest exact boundary result, complete
  identity-only observation directory, exact binding, and the verbatim active
  user-authored phase pointer.

Both use Qwen3.8-27B AD-IQ2_S, the same seeds, sampler, 512-token private
reasoning cap, 2,500-token response allowance, ordinary exact tools, P0, exact
observation reopen, and no semantic summary or host-selected relevance.

## Fresh geometries

1. **E7-SOURCE:** one unchanged governing source fact is needed after both
   boundaries, with an intervening candidate mutation and check.
2. **E7-OBSERVATION:** a Phase-A dynamic observation becomes stale after the
   Phase-B mutation; Phase B captures a new candidate-bound observation, and
   Phase C must select it instead of the still-accessible stale observation.

Each geometry runs two frozen seeds. Phase order is A -> boundary -> B ->
boundary -> C. A checkpoint is valid only after the stage-required exact reads,
mutation, and check. The second transition is prospective: the checkpoint call
must be admitted, while the next append-only request must fail the applicable
25k guard. The 50k control may stop mechanically when its exact append-only
chronology reaches physical capacity.

## Primary gates

The recurrent treatment passes only if it:

- reaches both exact boundaries without rescue;
- never reactivates completed phases;
- reacquires the current governing source or observation before mutation;
- rejects stale observation use in favor of the current candidate binding;
- preserves candidate/check/action/result bindings;
- remains below 25k for every admitted request;
- passes the final public and hidden graders and submits;
- uses one attempt per call, no retry, repair, rescue, or cross-cell history.

Report paired boundary success, seed divergences, recurrent failure modes,
stale-evidence errors, exact action-basis traces, tokens, time, reacquisition,
and closure. Mechanical integrity is zero-tolerance. Quality claims require
direct inspection of every prompt, output, result, and private-reasoning record.

## Prohibitions

No model-authored summary, relationship graph, embedding, learned retrieval,
semantic compression, ranking, retention declaration, richer metadata,
unrestricted reasoning, new evidence tool, automatic successor, or evaluator
access before the response seal.
