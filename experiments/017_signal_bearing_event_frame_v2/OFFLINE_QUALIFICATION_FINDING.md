# Experiment 017 Offline Qualification Finding

## Disposition

Pass for one exposed development-only live qualification. Fresh large-world
construction and measured claims remain unauthorized.

## Signal contract

V2 does not ask Qwen to infer progress from an opaque handle. Every resident
event preserves exact mechanical facts:

- action type and readable path/target;
- expected predecessor candidate and file identities;
- accepted/rejected status;
- successor candidate/file identity;
- check status and binding, read range/continuation, or terminal binding when
  applicable;
- the names, sizes, and hashes of bulky fields available externally.

For patch events, only `old` and `new` leave the resident action. A phase-scoped
`EVT-nnnn` address can reopen those exact fields. Result bodies remain behind
their existing `RES-nnnn` addresses. The frame says explicitly that handles
are addresses, not semantic evidence.

## Capacity

Both Experiment 016 sixteen-event stress cases now fit X25 after payload
externalization:

| Stress case | All 16 external | 15 external + 1 maximum resident |
|---|---:|---:|
| maximum-schema ASCII patch | 11,426 prompt tokens | 12,947 |
| reasoning-compatible escaped patch | 11,590 prompt tokens | 15,027 |

With the 512-token runtime allowance and 2,500-token output reserve, the worst
one-new-event request consumes 18,039 of 25,000 tokens, leaving 6,961 tokens.

The all-resident escaped case still exceeds R50, which is the expected authentic
pressure condition. The exact guard denies it before transport. R50 and X25
use byte-identical V2 requests before externalization.

## Exact access and replay

`reopen_event(EVT-nnnn)` returns the exact custodied action-payload object and
verifies its size/hash against the event. The existing result handle remains
separate. Resident events reconstruct the exact original response/result pair;
external events preserve the same pair identity.

Six scripted branches passed. The four donor branches checked and submitted.
Both historical-action branches followed:

```text
read current report
→ reopen exact historical action payload
→ patch using the recovered marker
→ check
→ submit
```

## Frozen live scope

The authorized live run contains six branches, two fixed seeds, one attempt per
branch, at most six calls per branch, no retries/repairs/rescue, and a maximum
of 36 HTTP completions. It uses the exposed donor cases plus one sacrificial
development case. It cannot support a measured large-world claim.
