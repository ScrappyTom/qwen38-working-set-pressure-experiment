Looking at the current code in verifiers.py:

For `_safe_relative_path`:
```python
def _safe_relative_path(path_or_name: str) -> PurePosixPath | None:
    normalized = path_or_name.replace("\\", "/")
    path = PurePosixPath(normalized)
    if path.is_absolute() and ".." in path.parts or not path.parts:
        return None
    return path
```

The issue here is operator precedence. `path.is_absolute() and ".." in path.parts or not path.parts` is evaluated as `(path.is_absolute() and ".." in path.parts) or (not path.parts)`. This means:
- An absolute path WITHOUT ".." would NOT be rejected (only absolute paths WITH ".." are rejected)
- The condition should reject ALL absolute paths, ALL parent traversal, AND empty paths

The fix should be:
```python
def _safe_relative_path(path_or_name: str) -> PurePosixPath | None:
    normalized = path_or_name.replace("\\", "/")
    path = PurePosixPath(normalized)
    if not path.parts or path.is_absolute() or ".." in path.parts:
        return None
    return path
```
