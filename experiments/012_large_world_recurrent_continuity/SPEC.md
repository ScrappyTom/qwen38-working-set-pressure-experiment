# Experiment 012 — Larger-world recurrent continuity

## Question

Does the earned minimal controller preserve correct purpose, evidence validity,
and closure through three authentic 25k reconstruction boundaries when the
candidate world is large enough that one complete resident P0 inventory is no
longer admissible?

## Frozen controller

Both conditions use the same Qwen3.8-27B AD-IQ2_S actor, server-enforced
512-token private reasoning, maximal exact whole-line paging, exact candidate
and observation bindings, exact external custody, public checks, one attempt,
and no retry, repair, rescue, or cross-cell history.

The only scaling change is hierarchical readable P0:

```text
small complete top-level root
        -> p0_page(directory)
        -> p0_page(file outline)
        -> exact read or observation reopen
```

Pages contain paths, sizes, symbols, signatures, and ranges. They contain no
task-aware ranking, summary, relationship graph, semantic selection, or source
body. Qwen chooses the object and page. The host chooses only deterministic
bounded transfer size.

## Conditions

- `C50`: exact append-only chronology under the 50,176-token physical context.
- `T25`: the same work under a 25,000-token active ceiling. At an authentic
  prospective capacity denial, it retains exact task, active user-authored
  phase, completed phase IDs, current candidate, observation identities,
  latest boundary receipt, budgets, and hierarchical P0 root. Bulk chronology
  remains in exact external custody.

## Fresh geometries

- `E12-SOURCE-ORBIT`: an exact governing source changes after the second
  boundary. The final phase must reacquire the current source rather than rely
  on its earlier value.
- `E12-OBS-COMPASS`: three successive candidate-bound compatibility
  observations remain available. Later phases must select and reopen the one
  bound to the current candidate among stale exact predecessors.

Each candidate contains 160 files and more than two million UTF-8 bytes. Each
task has four prospectively authored phases and three intended pressure
transitions. Two frozen seeds yield four shared prefixes and eight branches.

## Primary outcomes

- hidden-correct terminal candidate;
- public check and submission;
- number of authentic reconstruction boundaries crossed;
- current-versus-stale source/observation selection;
- completed-phase preservation without reactivation;
- candidate/check/version binding;
- physical C50 stop versus continued T25 capability.

Calls, prompt/completion tokens, elapsed time, P0 expansions, exact reads,
observation reopens, and closure headroom are secondary economics.

## Interpretation limits

This study tests larger synthetic Python worlds with exact user-authored phase
structure. It does not test model-authored planning, semantic summaries,
embeddings, relationship graphs, arbitrary documents, multimodal evidence, or
another actor profile.
