# Experiment 009: recurrent observation validity under host v2

This fresh observation-only study tests the remaining high-value recurrent
question from Experiment 008: after two authentic pressure transitions, can the
actor select and use exact candidate-bound current evidence while an older
exact observation remains available but stale?

Two lexically fresh sibling tasks, `E9-OBS-ALPHA` and `E9-OBS-BETA`, each run
seeds 173205 and 223607. Each prefix is forked into a 50k append-only control
(`C50`) and the 25k reconstructed treatment (`T25`). Conditions are
counterbalanced. Each call uses Qwen3.8-27B-AD-IQ2_S with a 512-token private
reasoning allowance, one attempt, and no retry, repair, rescue, or cross-cell
history.

The host-v2 controller is part of the prospective treatment. T25 reconstructs
at a mechanically denied prospective request, not merely because a scripted
qualification predicted a boundary. If the next Phase-C request remains under
25k, the host continues exact active history until an actual denial. One later
runtime denial may trigger the second exact reconstruction; another denial
fails closed. A denied preflight is a prepared invocation, not an HTTP/model
action.

The model-facing substrate is unchanged: exact authorized purpose, exact
candidate/version state, readable P0 orientation, ordinary exact tools, an
exact observation directory, and exact observation reopen. The host does not
mark an observation as stale or select relevance. The directory exposes exact
candidate bindings; Qwen must compare those bindings with current state.

Each Phase-B compliant path needs eight actions, leaving four of the frozen
twelve-action budget for actor-selected exploration or redundant acquisition.
The two custody files preserve pressure mass without recreating Experiment
008's four-file action squeeze.

Primary gates:

- both authentic T25 transitions are mechanically evidenced;
- current, not stale, exact observation is reopened before Phase-C mutation;
- candidate/check/version bindings remain exact;
- final public and hidden checks pass and the actor submits;
- every request is admitted under its condition ceiling;
- no host-selected relevance, rescue, retry, or semantic summary occurs.

C50 is a behavioral control while physically viable and a mechanical capacity
reference afterward. A physical C50 stop is not actor failure.

Every live transcript, including private reasoning, must receive direct review.
Results must state what Qwen saw, what it did, what the host did next, and the
resulting interpretation. Host defects are fixed and requalified before any
fresh measured exposure; historical evidence is never rewritten.

No new metadata, relationship graph, embedding, ranking, learned retrieval,
semantic compression, declaration, evidence tool, or unrestricted reasoning is
authorized.
